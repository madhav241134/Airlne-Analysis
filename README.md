# ✈️ Flight Price Analytics

## 📌 Project Overview
Flight Price Analytics is an end-to-end Data Analytics project focused on understanding flight fare variations across airlines, routes, travel classes, and departure conditions. The project uses Python, MySQL, statistical analysis, and Power BI to explore pricing patterns and build an interactive dashboard for data-driven insights.

## 🎯 Business Problem
Flight ticket prices vary depending on several factors, making it difficult for customers to compare fares and make informed booking decisions. This project analyzes flight pricing data to identify patterns and understand which factors are associated with ticket prices.

## 🎯 Project Objectives
- Analyze fare variations across airlines and routes.
- Compare Economy and Business class pricing.
- Investigate the relationship between ticket prices and days left before departure.
- Identify routes with high fare variability.
- Explore factors associated with flight ticket prices.
- Develop an interactive Power BI dashboard to present insights.

## 📊 Dataset Information
- **Total Records:** 300,153
- **Total Columns:** 11
- **Target Variable:** Price

### Dataset Features
| Column | Description |
|---|---|
| Airline | Airline operating the flight |
| Flight | Flight identifier |
| Source City | Departure city |
| Departure Time | Departure time category |
| Stops | Number/category of stops |
| Arrival Time | Arrival time category |
| Destination City | Arrival city |
| Class | Travel class |
| Duration | Flight duration |
| Days Left | Days remaining before departure |
| Price | Listed ticket fare |

## 🛠️ Tools & Technologies
- **Python:** Data cleaning, EDA, data preprocessing
- **Pandas & NumPy:** Data manipulation and analysis
- **Matplotlib & Seaborn:** Data visualization
- **MySQL:** SQL queries and analytical data exploration
- **Statistics:** Hypothesis testing and analysis of fare differences
- **Power BI:** Interactive dashboard development and data visualization

## 🔍 Project Workflow
1. **Data Preparation:** Inspected the dataset, checked data quality, and prepared data for analysis.
2. **Exploratory Data Analysis:** Explored distributions, patterns, and relationships between flight attributes and prices.
3. **SQL Analysis:** Used filtering, grouping, aggregation, and analytical queries to compare fares.
4. **Statistical Analysis:** Investigated differences in average fares and relationships between categorical and numerical variables.
5. **Dashboard Development:** Created an interactive Power BI dashboard to visualize pricing trends and comparisons.
6. **Business Insights:** Connected analytical findings with practical flight fare comparison questions.

## 💡 Key Business Questions
- Which airline offers the lowest average fare on each route?
- Are fares higher for last-minute listings than for early listings?
- How do listed fares vary with the number of days left before departure?
- Does the fare gap between Economy and Business vary across airlines?
- Which routes have the largest variation in listed fares?
- Is there a combined effect of airline and travel class on ticket prices?
